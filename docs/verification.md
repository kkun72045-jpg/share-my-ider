# 0.1.0 验证记录

以下记录只对应本仓库的原创原型，不沿用旧 Anywear 包的测试结论。

## 2026-10-01 实测结果

- **26/26 单元测试通过**：20 项凭证服务、4 项输入/状态规则、2 项手机包配置；全部采用本地或模拟上游，不调用收费服务。
- **生产构建通过**：TypeScript 检查、电脑扩展及两种手机开发包构建、完整依赖许可证集合已生成。
- **17 项浏览器冒烟检查通过，0 失败**：使用 Edge 154.0.4258.48 的独立临时配置，实际加载 `dist` 的 Manifest V3 扩展，并通过扩展运行时核对名称与清单版本。
- 真实工具栏 action 创建了 `SIDE_PANEL` 上下文，标签页数量保持 **2 → 2**；关闭面板后侧栏上下文 **1 → 0**，测试摄像头轨道停止。360px / 420px 面板无横向溢出。
- 网页选图在受保护页面不执行扫描；使用已有的 `127.0.0.1` 窄权限在受控商品页验证元数据收集，不重新请求图片。CDP 无法验证真实点击授予 `activeTab` 的过程，此项仍需人工检查。
- SDK 引擎页面加载、初始状态、服装上传选择、合成摄像头开关、未确认时的启动保护、无配置凭证服务提示、页面关闭停轨均通过；没有 CSP 事件或页面运行时错误。
- 该浏览器检查中外部请求、token 请求和上游模型调用均为 0；确认停止的合成视频轨道为 3 条。测试未宣称验证成功生成或计费流程。
- `npm audit` 在上述日期报告 0 个已知漏洞；这只反映当时的依赖数据库结果。

发现并修复了 MV3 不接受 `worker-src blob:`、Zod 的 JIT 探测触发 CSP，以及停止后晚到操作重新连接的时序问题。引擎使用本地打包 Worker，Zod 显式启用 `jitless`。

## 验证层次

- 单元测试：凭证 broker 的配置、来源、输入、限速、并发、上游错误及密钥边界；前端地址/图片规则和晚到异步操作失效机制。
- 构建检查：TypeScript 类型检查、生产构建及依赖许可证打包。
- 浏览器检查：使用独立临时浏览器配置与合成视频，不访问用户原有浏览器数据，不开启真人摄像头，不调用收费模型。
- 真实试衣：尚未验证。需要使用者配置自己的官方账户密钥与额度，再检查实际视频生成、服装一致性、延迟和停止行为。
- 手机：Firefox/Safari 开发包仅完成生成及配置检查；没有 Android/iPhone 真机、Safari 签名、远程 HTTPS 部署、摄像头权限或模型端到端验证。

浏览器测试中的合成视频只验证相机资源和界面逻辑，不冒充 AI 生成结果。静态界面预览与实际扩展加载的结果应分别记录。
